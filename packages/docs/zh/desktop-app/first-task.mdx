---
title: "运行你的第一个任务"
sidebarTitle: "第一个任务"
description: "安装 OpenWork 桌面应用，选择一个文件夹和一个模型，运行第一个任务。无需登录。"
---

<Steps>
  <Step title="安装">
    为 macOS、Windows 或 Linux [下载 OpenWork](/start-here/downloads)。
  </Step>
  <Step title="选择文件夹">
    OpenWork 只在你授权的文件夹中工作。
  </Step>
  <Step title="选择模型">
    [使用 ChatGPT 登录](/start-here/connect-your-stack/sign-in-with-chatgpt)、[添加 API 密钥](/start-here/connect-your-stack/add-anthropic-api-key)，或[运行本地模型](/start-here/connect-your-stack/use-local-models)。
  </Step>
  <Step title="运行任务">
    可以从“总结这个文件夹。”开始。
  </Step>
</Steps>

下一步：[连接服务](/start-here/connect-your-stack/connect-services)、[从对话创建技能](/start-here/do-work-with-it/create-a-skill-from-chat)，或阅读[为什么要登录](/zh/desktop-app/why-sign-in)。
