---
title: "为什么要登录？"
description: "OpenWork 桌面应用无需账户就能完成哪些工作，登录 OpenWork Cloud 后又增加了哪些能力。"
---

登录是可选项。要登录，请打开 `Settings > Account`，然后点击 `Sign in`。

| 无需登录即可使用 | 需要登录 OpenWork Cloud |
| --- | --- |
| 在已授权的文件夹中就你的文件进行对话 | 你所在组织共享的 [连接](/start-here/connect-your-stack/connect-services)，例如 Gmail 或 Slack |
| [你自己的模型](/start-here/connect-your-stack/add-a-custom-llm)、API 密钥、[ChatGPT 登录](/start-here/connect-your-stack/sign-in-with-chatgpt)，或[本地模型](/start-here/connect-your-stack/use-local-models) | [OpenWork 推理](/start-here/connect-your-stack/openwork-vs-opencode-models)模型 |
| 本地工作区技能 | 从 `Settings > Library` 添加技能和插件、团队共享的技能，以及[分享你自己的技能](/start-here/do-work-with-it/publish-and-copy-a-skill) |
| 工作区中的[自定义 MCP 服务器](/start-here/connect-your-stack/add-an-mcp-server) | 自动化任务 |
| | [仪表盘](/dashboards/overview)和已保存的应用 |
| | 即使你的电脑休眠也能继续运行任务的云工作区 |

登录 ChatGPT 或其他模型提供商，与登录 OpenWork Cloud 是两件独立的事。
