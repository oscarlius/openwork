---

把组织的 OpenWork 技能、插件和连接提供给 Zed。

<Steps>
<Step title="添加服务器">
把下面这段加进 Zed 的 `settings.json`：

```json
{
  "context_servers": {
    "openwork": {
      "source": "custom",
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://api.openworklabs.com/mcp/agent"],
      "env": {}
    }
  }
}
```

</Step>
<Step title="登录">
`mcp-remote` 会打开浏览器。登录 OpenWork 并选择你的组织。
</Step>
</Steps>

<AccordionGroup>
  <Accordion title="切换组织">
    删除已保存的 `openwork` token，重启服务器，然后选择另一个组织。
  </Accordion>
  <Accordion title="支持状态">
    仅为安装步骤：以下步骤遵循 OpenWork 的 OAuth profile，但原生的端到端验证尚未完成。参见 [MCP 网关参考](/cloud/run-in-the-cloud/cloud-mcp#reference)。
  </Accordion>
</AccordionGroup>
