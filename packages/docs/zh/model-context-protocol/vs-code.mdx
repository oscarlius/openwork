---

把组织的 OpenWork 技能、插件和连接提供给 VS Code。

<Steps>
<Step title="添加服务器">
[一键安装到 VS Code](vscode:mcp/install?%7B%22name%22%3A%22openwork%22%2C%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Fapi.openworklabs.com%2Fmcp%2Fagent%22%7D)，或运行：

```sh
code --add-mcp '{"name":"openwork","type":"http","url":"https://api.openworklabs.com/mcp/agent"}'
```

</Step>
<Step title="登录">
依次执行 `MCP: List Servers` > `openwork` > `Start Server`，登录 OpenWork，并选择你的组织。
</Step>
<Step title="试一试">
试着问：“我当前连接的是哪个 OpenWork 组织？”
</Step>
</Steps>

<AccordionGroup>
  <Accordion title="手动配置">
    执行 `MCP: Open User Configuration`，或为单个工作区编辑 `.vscode/mcp.json`：

```json
{
  "servers": {
    "openwork": {
      "type": "http",
      "url": "https://api.openworklabs.com/mcp/agent"
    }
  }
}
```

  </Accordion>
  <Accordion title="切换组织">
    删除已保存的 `openwork` token，重新启动服务器，然后选择另一个组织。
  </Accordion>
  <Accordion title="支持状态">
    仅为安装步骤：以下步骤遵循 OpenWork 的 OAuth profile，但原生的端到端验证尚未完成。参见 [MCP 网关参考](/cloud/run-in-the-cloud/cloud-mcp#reference)。
  </Accordion>
</AccordionGroup>
