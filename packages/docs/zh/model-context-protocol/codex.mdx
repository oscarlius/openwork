把组织的 OpenWork 技能、插件和连接提供给 Codex。

<Steps>
<Step title="添加服务器">

```sh
codex mcp add openwork --url https://api.openworklabs.com/mcp/agent
```

在 Codex 桌面应用中，改为把该 URL 粘贴到 `codex://settings/connections`。

</Step>
<Step title="登录">

```sh
codex mcp login openwork
```

在浏览器中登录 OpenWork，并选择你的组织。

</Step>
<Step title="试一试">
试着问：“我当前连接的是哪个 OpenWork 组织？”
</Step>
</Steps>

<AccordionGroup>
  <Accordion title="切换组织">

```sh
codex mcp logout openwork
codex mcp login openwork
```

  </Accordion>
  <Accordion title="支持状态">
    仅为安装步骤：以下步骤遵循 OpenWork 的 OAuth profile，但原生的端到端验证尚未完成。参见 [MCP 网关参考](/cloud/run-in-the-cloud/cloud-mcp#reference)。

</AccordionGroup>
