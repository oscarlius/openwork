把组织的 OpenWork 技能、插件和连接提供给 Gemini CLI。

<Steps>
<Step title="添加服务器">

```sh
gemini mcp add --transport http openwork https://api.openworklabs.com/mcp/agent
```

</Step>
<Step title="登录">
启动 `gemini`，执行 `/mcp auth openwork`，在浏览器中登录 OpenWork，并选择你的组织。
</Step>
<Step title="试一试">
试着问：“我当前连接的是哪个 OpenWork 组织？”
</Step>
</Steps>

<AccordionGroup>
  <Accordion title="切换组织">
    删除已保存的 `openwork` token，再次执行 `/mcp auth openwork`，然后选择另一个组织。
  </Accordion>
  <Accordion title="支持状态">
    仅为安装步骤：以下步骤遵循 OpenWork 的 OAuth profile，但原生的端到端验证尚未完成。参见 [MCP 网关参考](/cloud/run-in-the-cloud/cloud-mcp#reference)。
  </Accordion>
</AccordionGroup>
