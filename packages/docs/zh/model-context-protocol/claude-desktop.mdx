sidebarTitle: "Claude Desktop"
description: "在 Claude Desktop 中把 OpenWork MCP 作为自定义连接器添加，URL 用 https://api.openworklabs.com/mcp/agent，也可以通过 mcp-remote 接入。"
---

把组织的 OpenWork 技能、插件和连接提供给 Claude Desktop。

<Steps>
<Step title="添加自定义连接器">
依次打开 `Settings` > `Connectors` > `Add custom connector`，把它命名为 `OpenWork`，并使用：

```text
https://api.openworklabs.com/mcp/agent
```

</Step>
<Step title="登录">
点击 `Connect`，在浏览器中登录 OpenWork，并选择你的组织。
</Step>
<Step title="试一试">
试着问：“我当前连接的是哪个 OpenWork 组织？”
</Step>
</Steps>

<AccordionGroup>
  <Accordion title="你的版本里没有自定义连接器？">
    依次打开 `Settings` > `Developer` > `Edit Config`，把下面这段加进 `claude_desktop_config.json`，然后重启 Claude Desktop：

```json
{
  "mcpServers": {
    "openwork": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://api.openworklabs.com/mcp/agent"]
    }
  }
}
```

  </Accordion>
  <Accordion title="切换组织">
    删除已保存的 `openwork` token，然后重新连接并选择另一个组织。
  </Accordion>
  <Accordion title="支持状态">
    仅为安装步骤：以下步骤遵循 OpenWork 的 OAuth profile，但原生的端到端验证尚未完成。参见 [MCP 网关参考](/cloud/run-in-the-cloud/cloud-mcp#reference)。
  </Accordion>
</AccordionGroup>
