任何成员都可以在 OpenWork Cloud 里创建技能，并共享给需要它的人和团队。本页涵盖技能的创建、共享、查找和复制。

<Note>
**个人或托管。** 本地工作区技能是免费的，不需要登录 OpenWork Cloud。你在 OpenWork Cloud 里创建的技能一开始只属于你自己。什么时候共享出去，由你决定。
</Note>

## 为团队发布一个技能

### 1. 创建技能

在 OpenWork Cloud 里，一个技能存放在一个插件内。当你创建技能时，OpenWork 会为它建一个插件。

1. 在 OpenWork Cloud 控制台里打开 **My Library**，点击 **Add to your Library**。
2. 选择 **Skill**，然后点击 **Continue**。
3. 在 **Create a skill** 页面，填入 **Plugin name** 和一句简短的 **Description**。
4. 把技能填好：一个名字、AI 应该在什么时候使用它，以及用平实语言写出的步骤。
5. 要往同一个插件里再加内容，点击 **What's inside** 下的 **Skill**、**Command** 或 **Connector**。
6. 点击 **Create plugin**。

在你共享出去之前，只有你自己能用。

你也可以在桌面应用里通过 **Settings › Library › Add to library** 创建技能。
管理员可以通过 **Manage › Plugins › Create a plugin** 创建插件。

### 2. 选择谁可以使用它

**如果你是普通成员：**

1. 在 **My Library** 里打开该技能所属的插件，点击 **Share**。你也可以用该行 ⋯ 菜单里的 **Share**。
2. 在 **Who can use it** 下，点击 **Add person** 或 **Add team**，挑选应该获得它的人。
3. 点击 **Share with**，后面会带上人数。

你只能共享自己创建的东西。只有管理员才能共享给组织内的所有人。
在桌面应用里，你也可以通过 **Settings › Library** 共享：点开该条目的 ⋯ 菜单，
选择 **Share…**。

**如果你是管理员**（owner、super-admin 或 admin）：

1. 打开 **Manage › Plugins**，点击那个插件。
2. 在 **Who can use it** 下，打开 **Everyone in the organization**，
   或者点击 **Add person**、**Add team**。

这个页面上的改动会立即保存。当你添加访问权限时，会出现一条带 **Undo** 的提示，
方便你改主意。

要让某个人既能使用插件又能编辑它，请打开 ⋯ 菜单，选择 **Edit contents**，
再使用 **Who can access this**。挑一个人或团队，选择 **Can edit**，
点击 **Grant**。

<Tip>
要把同一批受众一次性配好几个插件，把它们归进一个 [Collection](/cloud/share-with-your-team/collections)。只有一个技能或一个插件时，直接共享更省事。
</Tip>

### 3. 在桌面应用里找到它

同事不需要安装任何东西。

1. 在桌面应用里打开 **Settings › Library**。
2. 在 **From OpenWork** 下查看，或者点击 **Skills** 筛选器。
3. 如果最近的改动还没出现，点击刷新按钮（它的 tooltip 写着 **Refresh**）。

现在同事可以直接用平实的语言提出这个任务。当请求和某个技能的描述匹配时，
AI 就会把它取用出来。

## 复制而不改动已共享的技能

当你编辑一个已共享的技能时，所有拿到它的人都会在各自下一次任务里得到这个改动。
想自己先试试改动，请先做一份副本。副本在你共享出去之前只属于你。

**你自己创建的技能：**

1. 在桌面应用里打开 **Settings › Library**。
2. 点开该技能的 ⋯ 菜单，选择 **Duplicate**。
3. OpenWork 会创建一个带 "(copy)" 后缀的副本。去编辑那个副本。

如果你已经开始编辑一个共享出去的技能，编辑页面会提供 **Save a copy just for me**。
它会把你的改动存成一个新技能，并保持被共享的那个原样不动。

**别人共享给你的技能：**

别人创建的技能没有复制按钮。请手工复制：

1. 在 **Settings › Library** 里打开这个共享技能，复制 **Instructions** 下的文本。
2. 点击 **Add to library**，选择 **Skill**，把说明粘贴到新技能里。
3. 给它一个新名字并创建。

如果你只是想做个小的个人化调整，也可以改成创建一个很短的技能，
告诉 AI 先使用那个共享技能、然后再套用你补充的步骤。
