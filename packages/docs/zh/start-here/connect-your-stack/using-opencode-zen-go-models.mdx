---
title: "接入 OpenCode Zen 与 Go 模型"
description: "把 OpenCode Go 提供商连接到 OpenWork Desktop"
---

OpenCode Zen 和 OpenCode Go 的模型由 OpenCode 提供，不是 OpenWork。如果你有 OpenCode 的订阅或 API 密钥，就在 OpenWork 桌面应用里连接 `OpenCode Go` 提供商。

<Note>
OpenCode 和 OpenWork 的模型订阅是各管各的。不确定自己订的是哪个，见 [OpenWork 与 OpenCode 模型的区别](/zh/start-here/connect-your-stack/openwork-vs-opencode-models)。
</Note>

## 在 OpenWork Desktop 里连接 OpenCode Go

1. 打开 OpenWork Desktop。
2. 点击左下角你的头像。
3. 打开 `Settings`。
4. 进入 `AI Providers`。
5. 点击 `Connect`。
6. 搜索 `opencode`。
7. 选择 `OpenCode Go`。
8. 点击 `Connect`，并在提示时输入你的 OpenCode API 密钥。

<Frame>
  ![Connect providers 弹窗中的 OpenCode Go 提供商](/images/opencode-go-connect-provider.png)
</Frame>

该提供商连接好之后，在聊天的模型选择器里选一个 OpenCode 模型即可。

## 管理你的 OpenCode 账户

- 在 [opencode.ai/go](https://opencode.ai/go) 了解 OpenCode Go。
- 在 [opencode.ai/auth](https://opencode.ai/auth) 管理你的 OpenCode 账户或认证。

如果 OpenWork 提示 OpenCode 密钥无效或模型不可用，请先检查你的 OpenCode 账户。OpenWork 不管理 OpenCode Go 或 OpenCode Zen 的计费。
