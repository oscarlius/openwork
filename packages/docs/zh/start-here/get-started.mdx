## 四步开始使用

<Steps>
  <Step title="安装">
    [下载 OpenWork](https://openworklabs.com/download)，支持 macOS、Windows 或 Linux。
  </Step>
  <Step title="选一个文件夹">
    OpenWork 只在你授权的文件夹里工作。
  </Step>
  <Step title="选择模型">
    [用 ChatGPT 登录](/start-here/connect-your-stack/sign-in-with-chatgpt)、[添加 API 密钥](/start-here/connect-your-stack/add-anthropic-api-key)，或者[运行本地模型](/start-here/connect-your-stack/use-local-models)。
  </Step>
  <Step title="跑一个任务">
    从“总结这个文件夹”开始。
  </Step>
</Steps>
