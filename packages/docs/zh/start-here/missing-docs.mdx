找不到你想要的内容？有两种解决办法。

## 让我们来写

[给团队发封邮件](mailto:team@openworklabs.com?subject=missing%20documentation&body=hey%20my%20github%20is%20%7Busername%7D%2C%20I%27m%20interested%20in%20%7Bfeature%7D%20from%20openwork%20but%20I%27m%20missing%20documentation%20on%20it%2C%20could%20you%20create%20it%3F%0A%0AThanks)。说明你想用的是哪个功能，我们就会把这篇文档补上。

## 自己来写

OpenWork 文档就在 [openwork 仓库](https://github.com/different-ai/openwork/tree/dev/packages/docs)里。新增一个 `.mdx` 页面，发起一个 pull request，我们会来审阅。
