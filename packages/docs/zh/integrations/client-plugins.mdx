[MCP 连接](/zh/integrations/mcp)为你的客户端提供技能和工具。客户端插件还会用一次登录把你所在组织的 AI 网关模型加入模型选择器。

## OpenCode —— 已就绪

在 OpenCode 2 中安装 [`opencode-openwork`](https://www.npmjs.com/package/opencode-openwork)。不需要桌面应用。

```sh
opencode plugin add opencode-openwork
opencode auth login openwork
```

选择 **Browser**，登录，选择你的组织，并确认匹配的验证码。此后每次启动 OpenCode 都会加载你的模型、技能和工具。

要求、检查项、自托管设置和登出方式：[OpenCode 插件指南](/model-context-protocol/opencode-plugin)。
