---
title: "仪表盘概览"
sidebarTitle: "概览"
description: "你的 OpenWork 仪表盘是什么，以及怎样往里添加应用。"
---

仪表盘是桌面应用侧边栏里 **Dashboard** 下的一页实时、可交互的应用。用它的条件是先登录 OpenWork Cloud，并且你的部署开启了仪表盘功能。

要添加应用，在聊天里让 OpenWork 做一个应用，或者把某个工作流的结果做成仪表盘。先看草稿预览，提出修改意见，然后选择 `Save` 把它加入你的仪表盘。只要该功能对你的组织开放，任何已登录的成员都能这样做。别人共享给你的应用也能在仪表盘里添加。

从聊天构建的应用只做展示和查看结果，不会提交审批或任何其他写入。

要自己构建 MCP App 组件，请按[构建 MCP App](/zh/dashboards/build-an-mcp-app)操作。
